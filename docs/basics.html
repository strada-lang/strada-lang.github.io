Language Basics

Core syntax and fundamental concepts of Strada.

Program Structure

A Strada program consists of function definitions. Execution begins at the main function:

# Comments start with #

func helper() {
    say("I'm a helper function");
}

func main() int {
    helper();
    say("Hello from main!");
    return 0;
}

Variables

Variables use Perl-style sigils. Type annotations are optional — the sigil determines the default type:

my $name = "Strada";          # scalar (any value)
my $count = 42;                # scalar
my $pi = 3.14159;              # scalar
my @colors = ("red", "green", "blue");  # array
my %config = ("debug" => 1, "port" => 8080);  # hash

# You can add explicit types for documentation and checking:
my int $total = 42;
my str $title = "Strada";
my num $ratio = 3.14159;

# $t, @t and %t are three different variables (as in Perl)
my %t; my @t; my $t;
$t{"k"} = 1;   # element of %t
$t[0] = 2;     # element of @t
$t = 3;

Declaring the same variable twice in one scope (my $x = 1; my $x = 2;) is a compile error.

Functions

Functions are defined with func (or fn). Types are optional:

# Simple function — no type annotations needed
func greet($name) {
    say("Hello, " . $name . "!");
}

func add($a, $b) {
    return $a + $b;
}

# No-parens form — args available as @_ (like Perl subs)
func log_msg {
    my $level = $_[0];
    my $msg = $_[1];
    say("[" . $level . "] " . $msg);
}

# With explicit types (for APIs, libraries, documentation)
func distance(num $x1, num $y1, num $x2, num $y2) num {
    return math::sqrt(($x2 - $x1) ** 2 + ($y2 - $y1) ** 2);
}

See the Functions page for closures, variadic functions, default parameters, and more.

Statements

Statements end with semicolons:

my $x = 10;
my $y = 20;
say($x + $y);
$x = $x + 1;

Comments

# This is a single-line comment

my int $x = 42;  # Inline comment

Comparison Operators

Numeric String Description
==eqEqual
!=neNot equal
<ltLess than
>gtGreater than

>=geGreater than or equal
<=>cmpSpaceship (returns -1, 0, or 1)
Spaceship operators: Use <=> for numeric sort and cmp for string sort: sort { $a <=> $b } @nums or sort { $a cmp $b } @strings. The block is a single comparison expression; a trailing ; or return is allowed.
Important Use eq/ne for string comparison, not ==/!=. Using numeric operators on strings compares them numerically.

Logical Operators

Operator Description Example
&&Logical AND (returns the deciding operand)$a && $b
||Logical OR (returns value)$h{"key"} || "default"
//Defined-or$h{"key"} // "default"
!Logical NOT!$a
notLow-precedence NOTnot $a
andLow-precedence AND (returns the deciding operand)$a and $b
orLow-precedence OR (returns value)my $fh = core::open($p, "r") or die("no $p");
xorLogical exclusive or (1 or "")$a xor $b
|| vs //: The || operator returns its left operand if truthy, otherwise its right operand (like Perl/JavaScript). The // operator returns its left operand if defined (not undef), otherwise its right operand. Use // when you want empty strings or zero to be considered valid values. && works the same way as in Perl: 1 && "v" is "v" and 0 && $x is 0. The words not, and and or/xor work like !, && and || but bind more loosely than assignment, as in Perl: in my $fh = core::open($p, "r") or die("...") the assignment happens first.

Increment/Decrement

my int $i = 0;

$i++;    # Postfix increment (returns old value)
$i--;    # Postfix decrement
++$i;    # Prefix increment (returns new value)
--$i;    # Prefix decrement

Assignment Operators

$x = 10;     # Assignment
$x += 5;    # Add and assign ($x = $x + 5)
$x -= 3;    # Subtract and assign
$x *= 2;    # Multiply and assign
$x /= 4;    # Divide and assign
$x .= "!";  # Concatenate and assign

Ternary and Other Operators

# Ternary conditional
my str $result = $x > 0 ? "positive" : "non-positive";

# Range operator (creates array)
my array @nums = (1..10);

# Reference operator
my int $x = 42;
my scalar $ref = \$x;      # Reference to $x

# Function reference
my scalar $fn = \&my_function;   # call it with $fn->()

Named Unary Operators (No Parentheses)

As in Perl, many built-ins can be written without parentheses when the argument is a variable, a \ reference or a literal. They bind like Perl's named unary operators, so keys %h > 1 means keys(%h) > 1:

my %h = ("a" => 1, "b" => 2, "c" => 3);
my @a = (1, 2);
say(scalar @a);                  # 2
say(uc "x");                    # X
delete $h{"a"};
if (keys %h > 1) { say("more than one"); }
my $first = shift @a;          # 1
say(exists $h{"b"} ? "yes" : "no");   # yes

The same applies to values, each, defined, ref, lc, length and similar functions. Nest calls with parentheses: write scalar(keys %h), not scalar keys %h.

Blocks

Blocks are delimited by curly braces and create a new scope:

{
    my int $x = 10;  # $x only visible in this block
    say($x);
}
# $x is not accessible here

Truthiness

Values are considered "false" if they are:

  • The number 0
  • The empty string "" and the string "0"
  • undef
  • An empty array or hash (if (@items), if (%seen))

Everything else is "true", including "0.0", "00", " " and every reference (even a reference to an empty array or hash).

if ($value) {
    say("Value is true");
} else {
    say("Value is false");
}

Magic Namespaces

Built-in functions are organized into namespaces:

Core Functions (No Namespace)

Perl-heritage functions like say(), print(), push(), pop(), length(), etc.

re::, str::, sb:: Namespaces

Strada-specific built-ins use namespaced spellings (the historical bare names remain as legacy aliases): re::match(), re::replace_all(), re::captures() for regex function forms; str::replace(), str::replace_first() for literal string replacement; sb::new(), sb::append(), sb::to_string() for StringBuilder. See the built-in function reference for the full alias list.

math:: Namespace

math::sin(3.14)
math::cos(0)
math::sqrt(16)
math::pow(2, 10)
math::abs(-5)
math::floor(3.7)
math::ceil(3.2)

core:: Namespace

core:: is the preferred namespace for system functions. (The legacy sys:: spelling still compiles, but the compiler prints a deprecation warning.)

core::open("file.txt", "r")
core::fread($fh, 1024)
core::fwrite($fh, $data)
core::close($fh)
core::fork()
core::exec("ls -la")      # replaces the process (runs via /bin/sh -c)
core::getenv("PATH")
core::time()

Regex Operations

Pattern Matching

my str $s = "Hello World";

# Match
if ($s =~ /World/) {
    say("Found it!");
}

# Negated match
if ($s !~ /Goodbye/) {
    say("Not found");
}

Substitution

my str $s = "Hello World";

# Replace first occurrence
$s =~ s/World/Strada/;

# Replace all occurrences (g flag)
$s =~ s/l/L/g;

# Case-insensitive (i flag)
$s =~ s/hello/Hi/i;

Input/Output

Console Output

say("With newline");      # Prints with newline
print("No newline");      # Prints without newline

Heredocs

Multi-line string literals using heredoc syntax:

my str $text = <<EOT;
This is a multi-line
string literal.
EOT

# Single-quoted: no escape sequences
my str $raw = <<'EOT';
Backslash-n stays literal: \n
EOT
Note: The semicolon goes on the <<EOT; line. Heredocs work exactly as in Perl: every body line keeps its newline, the last one too ($text above is "This is a multi-line\nstring literal.\n"; use chomp() to drop it). Bare <<EOT and <<"EOT" interpolate ${name} and process escapes; <<'EOT' and <<\EOT are literal. <<~EOT allows an indented body and terminator: the terminator's indentation is removed from every line.

chomp

chomp() strips trailing \n (or \r\n) from a variable in-place and returns the modified string:

my str $line = "hello\n";
chomp($line);   # $line is now "hello"

File I/O

# Read entire file
my str $content = slurp("file.txt");

# Write to file
spew("output.txt", $content);

# Low-level file operations
my scalar $fh = core::open("file.txt", "r");
my str $data = core::readline($fh);
core::close($fh);

# Perl-style open modes
my scalar $in  = core::open("file.txt", "<");   # read
my scalar $out = core::open("out.txt", ">");    # write
my scalar $log = core::open("log.txt", ">>");   # append

# STDIN, STDOUT, STDERR barewords
say(STDOUT, "to stdout");
say(STDERR, "error output");
my str $line = <STDIN>;

# File test operators
if (-e $path) { say("exists"); }
if (-f $path) { say("is a file"); }
if (-d $path) { say("is a directory"); }

Diamond Operator <$fh>

Read lines from filehandles using the Perl-style diamond operator:

# Scalar context: read one line at a time
my scalar $fh = core::open("input.txt", "r");
my str $line = <$fh>;
while (defined($line)) {
    say($line);
    $line = <$fh>;
}
core::close($fh);

# Array context: read ALL lines at once
$fh = core::open("input.txt", "r");
my array @lines = <$fh>;    # Reads entire file!
core::close($fh);

foreach (@lines) {    # Implicit $_ loop variable
    say($_);
}

Print/Say to Filehandle

Write to files or sockets using say/print with a filehandle as the first argument:

# Write to file
my scalar $out = core::open("output.txt", "w");
say($out, "Line with newline");    # Adds \n
print($out, "No newline");          # No \n
core::close($out);

# Also works with sockets!
my scalar $sock = core::socket_client("localhost", 80);
say($sock, "GET / HTTP/1.0");
my str $response = <$sock>;    # Read response
core::socket_close($sock);
