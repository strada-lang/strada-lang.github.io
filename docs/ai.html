Strada with AI coding tools

Install the Strada skill so your coding assistant can write, compile, test and debug Strada code with you.

Why a skill AI models know Perl well, and Strada looks like Perl, so without help they write Perl that doesn't compile. The Strada skill gives them what they need: the compile-and-check workflow, the places where Strada and Perl differ, the full language and builtin references, and a script that checks your toolchain. It loads only when you work on Strada code. It uses the open Agent Skills format (a folder with a SKILL.md), so the same skill works in Claude and in OpenAI Codex.

Current version: 2026.11.23. Source: claude/skills/strada in the Strada repository.

Install

Quick install: Claude Code and Codex

One command installs the skill for both Claude Code (~/.claude/skills) and OpenAI Codex (~/.agents/skills):

curl -fsSL https://strada-lang.github.io/claude/install.sh | sh

Options go after sh -s --:

# only one tool
curl -fsSL https://strada-lang.github.io/claude/install.sh | sh -s -- --claude
curl -fsSL https://strada-lang.github.io/claude/install.sh | sh -s -- --codex

# into the current project (.claude/skills and .agents/skills), to commit it
curl -fsSL https://strada-lang.github.io/claude/install.sh | sh -s -- --project

Run it again to update. It only replaces a folder named strada inside those skills directories, and it tells you if strada is not on your PATH yet. Start a new Claude Code or Codex session afterwards. Read the script before you pipe it into a shell.

Claude Code

Install it as a plugin, which also gives you updates through /plugin:

/plugin marketplace add strada-lang/strada-lang.github.io
/plugin install strada@strada-lang

Or install it as a plain skill with the quick install above, or by hand:

mkdir -p ~/.claude/skills
curl -fsSL https://strada-lang.github.io/claude/strada-skill.tar.gz | tar -xz -C ~/.claude/skills

To share it with everyone on one project, unpack it into that project's .claude/skills/ folder and commit it.

OpenAI Codex (CLI and IDE extension)

Ask Codex's built-in skill installer to fetch it. In Codex, type:

$skill-installer install the skill at https://github.com/strada-lang/strada-lang.github.io/tree/main/claude/strada

Or unpack it into your personal skills folder yourself:

mkdir -p ~/.agents/skills
curl -fsSL https://strada-lang.github.io/claude/strada-skill.tar.gz | tar -xz -C ~/.agents/skills

For one project, unpack it into .agents/skills/ at the repository root and commit it. Restart Codex if strada doesn't appear under /skills. Codex picks the skill when a task matches; to ask for it by name, type $strada or use /skills. See OpenAI's skills documentation for the current details.

Claude apps (claude.ai, desktop, mobile)

Download strada-skill.zip, then go to Settings → Capabilities → Skills, choose Upload skill, and pick the zip. Code execution must be turned on.

The sandbox there does not have Strada installed, so the assistant writes the code and you compile and run it on your machine. In Claude Code and Codex the whole loop runs locally.

Other tools

For an assistant without skill support, give it the language reference: a single Markdown file covering the whole language, written for AI models. Save it in your project:

mkdir -p docs
curl -fsSL -o docs/strada-reference.md https://strada-lang.github.io/claude/strada/reference/language.md

Then point the assistant at it from its instructions file (AGENTS.md, a rules file, or whatever your tool reads):

This project is written in Strada, not Perl. Before writing Strada code,
read docs/strada-reference.md. Check every change with
`strada --check FILE.strada`, then build and run it.

The builtin function list is at reference/builtins.md if your tool can take a second file.

Read what you install The quick-install script downloads the skill tarball from this site and copies it into your skills folders; nothing else. The skill itself contains two short shell scripts the assistant may run: scripts/check-toolchain.sh looks for strada and a C compiler and compiles a hello-world in a temporary directory, and scripts/strada-run.sh compiles a program into a temporary directory, runs it, and deletes the binary. Nothing else. You can browse every file of the skill here before installing it.

Before you start

A local coding agent runs Strada on your machine, so it needs the toolchain: strada on your PATH (after make install), or a strada-lang checkout where ./strada works, plus a C compiler. See the QuickStart. When the skill loads, the assistant runs the toolchain check first and tells you if anything is missing.

Programming Strada with an assistant

Ask for what you want in plain words. Mentioning Strada or having .strada files around is enough for the skill to load:

# a few prompts that work well
Write a Strada program that reads access.log and prints the 10 busiest IPs.
Add an Invoice class with line items and a total() method, plus tests.
This .strada file fails to compile, fix it.
Call libsodium's randombytes_buf from Strada through a __C__ block.
Port this Perl script to Strada.

The loop the skill teaches

  1. Write the code, with a func main() int entry point and no top-level statements.
  2. Run strada --check file.strada, which reports every syntax and type error with line, column and a caret, and fix them.
  3. Build at -O0 into a temporary directory and run the program (scripts/strada-run.sh), so you see real output and no stray binaries land in your project.
  4. For tests, write them with use Test; and run them under prove.
  5. For __C__ code, check for leaks with valgrind.

Tips

  • Let it run the compiler. Code that passed strada --check and ran is worth far more than code that only looks right. Allow the assistant to run strada, and ask it to show the program's output.
  • Watch the classic Perl slips when reviewing: Strada interpolates only "${name}" (a bare "$name" prints literally), system calls are core:: functions, and there is no qr//. The skill teaches these; they are still the first things to check.
  • Ask for types on hot code. my int $i and int parameters make arithmetic allocation-free; ask for typed loops and numeric functions.
  • Quick experiments don't need a build: strada-interp file.strada (the bytecode VM) or the REPL (strada --repl) run code directly.
  • Porting Perl: give the assistant the Perl script and ask for a Strada version that prints the same output; have it run both and compare.
  • Project notes: put your project's conventions (module layout, how to run its tests) in the file your tool reads at startup: CLAUDE.md for Claude Code, AGENTS.md for Codex. The skill covers the language; that file covers your code.

What's in the skill

FileContents
SKILL.mdThe workflow, Strada-versus-Perl pitfalls, an OOP example, __C__ rules, and when to read the references.
reference/language.mdThe whole language in one file, written for AI models: syntax, OOP, regex, I/O, async, modules, idioms, gotchas.
reference/builtins.mdEvery builtin function by namespace (core::, math::, async::, c::, ...).
scripts/check-toolchain.shFinds strada and a C compiler and compiles a hello-world.
scripts/strada-run.shCompile, run and clean up in one step; also a prove --exec test runner.
VERSIONThe skill version and the Strada commit it was built from.

The references are built from the Strada repository's docs each release, so the skill tracks the compiler. Update it when you update Strada.
